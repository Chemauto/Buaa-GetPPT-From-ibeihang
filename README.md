# BuaaGetPPt

提取智学北航（classroom.msa.buaa.edu.cn）课堂回放中的全部 PPT：下载每页幻灯片原图（1280×720），并自动合成为一个 PDF 文件。

提供两种使用方式：**网页操作界面**（推荐）和命令行。工具在登录状态下读取回放页的 PPT 列表接口（含每页原图与时间点），因此能拿到完整的全部页面；首次运行在弹出的浏览器窗口里登录一次北航账号（支持统一身份认证扫码），登录状态保存在本地 `.browser_profile` 目录，之后无需再登录。

## 环境要求

- Windows（macOS / Linux 亦可，"打开文件夹"按钮仅支持 Windows）
- Python 3.10+
- 本机已安装 Chrome 或 Edge

## 安装

```bash
cd BuaaGetPPt
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

## 使用

### 网页界面（推荐）

```bash
python webui.py
```

运行后自动打开浏览器页面（http://127.0.0.1:8765），粘贴回放页链接，点击"开始提取"：

- 实时显示提取进度、页数和日志；
- 需要登录时工具会弹出浏览器窗口，完成一次登录后长期有效；
- 完成后可直接在页面里查看 PDF、打开输出文件夹、预览幻灯片缩略图。

### 命令行

```bash
python main.py "https://classroom.msa.buaa.edu.cn/livingroom?course_id=xxxx&sub_id=xxxx&tenant_code=21"
```

从回放页面地址栏复制完整链接即可。可选参数：

| 参数 | 说明 |
| --- | --- |
| `--out 目录` | 指定输出目录（默认 `output/<时间戳>`） |
| `--keep-duplicates` | 不合并重复的幻灯片（老师重复讲解同一页时保留多页） |
| `--headless` | 无头模式运行浏览器（首次登录时不要使用） |
| `--login-timeout 秒` | 等待登录的最长时间，默认 600 |

## 输出内容

输出目录按「课程名 / 周次节次」自动组织（取自回放页标题，如 `科学写作与报告` / `第3周星期2第3,4节`），重复提取同一讲时自动追加序号不会覆盖：

```
output/
└── <课程名>/
    └── <第N周星期X第X,X节>/
        ├── <课程名><周次节次>.pdf        # 全部幻灯片按页序合成的 PDF
        └── slides/
            ├── slide_001.jpg             # 逐页幻灯片原图
            ├── slide_002.jpg
            └── ...
```

## 常见问题

**首次运行提示登录后没有反应？** 登录完成、页面跳回回放页后工具会自动继续，耐心等待即可；扫码登录通常最快。

**图片清晰度？** 提取的是回放页实际加载的幻灯片图片（平台提供的 1280×720），满足阅读与打印笔记用途；平台不提供 PPT 源文件下载，这是可获取的最高质量版本。

**提取页数和回放页侧边栏对不上？** 属正常现象：侧边栏缩略图按需懒加载，工具通过接口一次性获取全部页面，通常比侧边栏看到的更完整。

**某次提取报错或页数为 0？** 检查回放链接是否完整（地址栏整段复制），确认该课程回放对你可见；命令行模式下失败时输出目录里会留有 `debug_no_thumbs.png` 调试截图，便于排查。
